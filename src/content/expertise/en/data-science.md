### What I do

- **Forecasting and time series**: seasonality, external drivers, uncertainty intervals rather than a single number.
- **Computer vision**: image classification, object detection and segmentation, from annotation to evaluation.
- **Scoring and tabular models**: gradient boosting, calibrated probabilities, metrics chosen from the real cost of each kind of error.
- **Geostatistics**: footfall and mobility data, mapping, automated consistency checks.
- **NLP**: automatic processing of customer emails.

### How I validate

- Train and test splits that respect time, so no future information leaks into training.
- A simple baseline first; a complex model is kept only if it clearly beats it.
- Every reported number comes with the command that produced it, including when the result is disappointing.

### How I deliver

Reproducible pipelines, automated tests and code that a colleague can read, run and maintain without me.
